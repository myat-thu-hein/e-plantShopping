# Paradise Nursery Shopping Application

Paradise Nursery, also known as **e-plantShopping**, is an online houseplant shopping application built with React and Redux Toolkit.

## About the Project

This application allows customers to browse and purchase a variety of houseplants. Plants are organized into multiple categories, and every plant is displayed with its image, name, description, and price.

Customers can add plants to a shopping cart, change product quantities, remove products, and view the total cost of their order.

## Features

- Paradise Nursery landing page
- Product listing page
- Plants organized into multiple categories
- Plant images, names, descriptions, and prices
- Add to Cart buttons
- Dynamic cart quantity
- Increase and decrease quantity buttons
- Delete products from the cart
- Individual product totals
- Complete shopping-cart total
- Continue Shopping button
- Checkout button

## Technologies Used

- React
- JavaScript
- Redux Toolkit
- React Redux
- HTML
- CSS
- Vite

## Run the Application

Install the project dependencies:

`npm install`

Start the development server:

`npm run dev`

Then open the local URL displayed in the terminal.
